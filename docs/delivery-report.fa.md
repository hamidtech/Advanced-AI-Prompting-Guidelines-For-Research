# گزارش تحویل نسخهٔ ۲.۰

[English](delivery-report.md) · تاریخ ۲۰۲۶-۱۰-۳۱ · [بازبینی مستقل](independent-review.fa.md)

## ممیزی و معماری

پنج فایل و هشت کامیت مبنای `59e3911` بررسی شد. لینک راهنمای مدرن شکسته بود؛ ایده با شکاف تأییدشده مرز روشنی نداشت و ثبت منشأ، افشای AI، حریم خصوصی، ارزیابی و CI وجود نداشت. [ممیزی و نقشهٔ مهاجرت](audit-and-migration.md) پیش از تغییر فایل‌های ریشه ثبت شد.

سه لایه پیاده شده است: شروع ساده با پرامپت قابل کپی؛ گردش‌کار پژوهشی مبتنی بر شواهد؛ و ساختار و خودکارسازی اختیاری. لایه‌های اول و دوم به API یا برنامه‌نویسی وابسته نیستند. ورودی‌های فارسی و انگلیسی بر اساس نیاز کاربر طراحی شده‌اند. مجوز MIT و انتساب نویسنده حفظ شده است.

## مهاجرت و محتوا

پنج فایل اصلی در `legacy/2024-gpt-4o/` بدون تغییر بایت‌ها حفظ شده‌اند. فایل‌های ریشه مسیر ورود جدید و پیوند آرشیو دارند؛ نشانی نام فایل‌ها برقرار است، اما عنوان‌بخش‌های تاریخی ممکن است به نسخهٔ آرشیوی نیاز داشته باشند. فایل ModernResearchPrompting اکنون وجود دارد. نام آرشیو به پیشینهٔ GPT-4o اشاره می‌کند، نه تاریخ آخرین ویرایش.

[ده پرامپت](../catalog/prompts/) دوزبانه با شناسه‌های RP-01 تا RP-10 شامل ایده‌پردازی پایان‌نامه، زاویهٔ مقاله، ایدهٔ کتاب، عنوان میان‌رشته‌ای، فرضیهٔ شکاف، کشف علاقه، نقد موضوع، اصلاح عنوان، تلفیق پیشینه و امکان‌سنجی هستند. هرکدام ورودی توضیح‌داده‌شده، متن کامل، مثال پرشده، پیگیری، خطا و نسخه دارند. مثال‌ها آموزشی‌اند و خروجی اجرای مدل نیستند.

[چهار گردش‌کار](../catalog/workflows/) از علاقه تا عنوان، اعتبارسنجی موضوع، بررسی شکاف و از مقاله تا شواهد، قرارداد خروجی و مرحله‌های راستی‌آزمایی دارند. [پنج حوزه](disciplines/) مهندسی، علوم زیستی، علوم اجتماعی و مدیریت، ادبیات و علوم انسانی، دین و الهیات پوشش داده شده‌اند؛ روش تجربی بر پژوهش تفسیری تحمیل نشده است.

## منابع و تغییرات علمی

قرارداد پرامپت، ساختارهای تاریخی را ابزار سازمان‌دهی می‌داند و حالت کاوش را از دمای API جدا می‌کند. زمینه، استدلال، OCR، شِما، عامل، منشأ، حریم خصوصی و افشا مستند شده‌اند. [ماتریس ابزار](tools/capability-matrix.fa.md)، [مدل‌ها](tools/models.fa.md)، [دفتر منابع](tools/sources.fa.md) و [درستکاری پژوهش](integrity/research-integrity.fa.md) تاریخ و محدودیت بررسی را نشان می‌دهند. منابع رسمی ارائه‌دهندگان، زیرساخت علمی، ICMJE، COPE، Nature، PRISMA و Cochrane استفاده شده‌اند.

## آزمون و ارزیابی

شِماهای فرادادهٔ پرامپت و گردش‌کار، رکورد شواهد و موضوع، به‌علاوهٔ شِماهای سناریو و اجرای ارزیابی آماده‌اند. اعتبارسنج آفلاین پیوندها، فایل‌های لازم، جفت زبان، جای‌خالی‌ها، شناسه‌ها، ارجاع‌ها، قالب پایه، بایت‌های آرشیو و توازن سی سناریو را بررسی می‌کند. آزمون‌های منفی موارد نامعتبر را رد می‌کنند.

چهارده آزمون خودکارسازی و سه روش آزمون زیرساخت ارزیابی موفق بوده‌اند؛ یازده تغییر نامعتبر در رکورد اجرا نیز آزموده شده است. اجرای آزمایشی برنامه‌ریز، ۳۶۰ رکورد برنامه‌ریزی ساخت. دستورهای دقیق در [گزارش انگلیسی](delivery-report.md) و [خودکارسازی](../automation/README.fa.md) آمده‌اند. نصب گردش‌کار CI با اجرای واقعی آن متفاوت است؛ اعتبارسنج نهایی محلی با ۱۰ پرامپت، ۴ گردش‌کار، ۳۰ سناریو و ۷۹ سند Markdown جاری بدون خطا موفق شد؛ وضعیت CI جداگانه در Pull Request گزارش می‌شود. نمودار Mermaid از نحو متعارف استفاده می‌کند؛ آزمون واقعی رندر GitHub در این گزارش ادعا نشده است.

**هیچ مدل پژوهشی اجرا نشده، امتیاز تخصصی ثبت نشده و بهبود تجربی اندازه‌گیری نشده است.** سی سناریو شش وضعیت ورود را در پنج رشته پوشش می‌دهند؛ فقط شش پرامپت مستقیماً در این مجموعه آزموده خواهند شد. چهار پرامپت دیگر و ورودی چندوجهی و ابزارها برای ادعای پوشش کامل به سناریوهای بیشتری نیاز دارند.

## بازبینی و محدودیت‌ها

بازبین AI جداگانه هشت منظر علمی، فنی، دسترس‌پذیری، زبان، نگهداری، امنیت، ارجاع و روش ارزیابی را بررسی کرد. کنترل نام بازبین شواهد بررسی‌شده، تطبیق شناسهٔ منبع، جفت زبان، دادهٔ خراب، توازن سناریو و آزمون‌های تغییر عمدی تقویت شدند. این بازبینی معادل تأیید متخصص انسانی نیست.

قابلیت حساب‌های تجاری یا API مدل‌ها آزمایش نشده است. دسترسی مستقیم COPE و Nature مسدود بود و متن جست‌وجوی رسمی با برچسب محدودیت استفاده شد. بازیابی API ابزار Elicit ناموفق بود؛ قرارداد API ابزار SciSpace و قالب دقیق خروجی ResearchRabbit تأیید نشده‌اند. عبور از CI اعتبار علمی، پوشش کامل منابع یا تازگی را ثابت نمی‌کند.

## تحویل GitHub و نسخهٔ بعد

شاخهٔ اختصاصی `v2/evidence-based-research-workflows` برای پیش‌نویس PR علیه main است. ادغام، انتشار Release و تغییر تنظیمات یا دسترسی مخزن انجام نمی‌شود. تاریخچهٔ شاخه و گفت‌وگوی PR مرجع نهایی کامیت و انتقال هستند.

اولویت نسخهٔ ۲.۱: بازبینان دوزبانهٔ رشته‌ای و اجرای پایلوت کنترل‌شده؛ بسته‌های منابع مجاز و سناریوهای چهار پرامپت باقی‌مانده و خطاهای OCR و ابزار؛ بررسی مجدد قابلیت‌های متغیر و سیاست‌های مسدود؛ و کالیبراسیون معیارها پیش از گزارش برتری. این‌ها پیشنهاد آینده‌اند، نه آزمایش انجام‌شده.
