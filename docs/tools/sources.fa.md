# ثبت منابع و وضعیت بررسی

[English](sources.md) · [جدول ابزارها](capability-matrix.fa.md)

تاریخ تلاش برای دسترسی همه منابع: **۲۰۲۶-۱۰-۳۱**. «باز شد» دریافت متن رسمی است؛ به‌معنای آزمایش سرویس، بررسی کامل همه پیوندها یا تأیید تجربی ادعای فروشنده نیست. موارد جست‌وجویی عمداً از بررسی مستقیم جدا شده‌اند. مسیرهای تغییرکرده و خطاها حفظ شده‌اند تا محدودیت پنهان نماند.

| شناسه | منبع رسمی | وضعیت دسترسی | ادعای پشتیبانی‌شده و حد آن |
|---|---|---|---|
| S01 | [OpenAI model catalog](https://developers.openai.com/api/docs/models) | باز شد | نام مدل‌های جاری؛ بدون مقایسه تجربی. |
| S02 | [OpenAI reasoning](https://developers.openai.com/api/docs/guides/reasoning) | باز شد | راهنمای استدلال؛ تنظیم دقیق به مدل وابسته است. |
| S03 | [OpenAI structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs) | باز شد؛ بخش مرتبط بررسی شد | خروجی منطبق با طرح‌واره همچنان ممکن است اشتباه باشد. |
| S04 | [OpenAI web search](https://developers.openai.com/api/docs/guides/tools-web-search) | باز شد | بازیابی و ارجاع در API؛ نه دسترسی همگانی ChatGPT. |

| S26 | [PRISMA](https://www.prisma-statement.org/) | باز شد | راهنمای گزارش و افزونه‌ها؛ نه گواهی کیفیت. |
| S27 | [Cochrane Handbook](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current) | باز شد؛ فهرست مطالب بررسی شد | روش مرور مداخله، انتخاب، استخراج و سوگیری؛ نه روش عمومی علوم انسانی. |

## نگهداری

پیش از تغییر ادعای فنی، صفحه رسمی مرتبط را باز کنید؛ تاریخ و دامنه متن مشاهده‌شده را به‌روز کنید. وجود پیوند با بررسی آن فرق دارد. در صورت شکست دسترسی، ادعا را محدود کنید یا بررسی را در انتظار بگذارید. این فهرست ادعای دسترسی به متن کامل مقالات تجاری یا همه پایگاه‌های رشته‌ای ندارد. هیچ API تجاری، اشتراک یا حساب کاربری در این مرحله آزمایش نشد.
