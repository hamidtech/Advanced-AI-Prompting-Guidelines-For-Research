## A practical combination

For a beginner: explore with any accessible assistant, search in a discipline-appropriate scholarly database, read selected papers, save verified references in Zotero, then use the [paper-to-evidence workflow](../../catalog/workflows/paper-to-evidence.md). No API is required.

For automation: retrieve metadata through a documented, authorized scholarly API; retain raw responses; resolve source documents legally; extract and validate records; route ambiguous entries to a human. An API supplying metadata does not automatically grant permission to download or redistribute full texts.

## Coverage checks before a review

Choose several known relevant records in each important language and publication type. Check whether the selected service retrieves them; record failures. Compare query variants, specialist databases and citation chains. Treat this as a coverage diagnostic, not proof of completeness. Keep a search log with database, exact query, date, filters, result count, screening decision and deduplication rule. See [integrity safeguards](../integrity/research-integrity.md).
