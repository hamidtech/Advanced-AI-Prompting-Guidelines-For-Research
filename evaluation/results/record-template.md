# Manual run record / فرم ثبت اجرای دستی

Duplicate this template outside tracked results when working with private inputs. Store a redacted record only after review. An empty template is not a completed run.

| Field / فیلد | Recorded value / مقدار |
|---|---|
| Run ID; case; arm; repetition; language / شناسه، سناریو، بازو، تکرار، زبان | Not run / اجرا نشده |
| Repository commit; prompt version/hash; scenario hash / کامیت و نسخه و هش | Pending / در انتظار |
| Exact rendered prompt; binding map; evidence packet hash / پرامپت، جای‌خالی‌ها، بسته شواهد | Pending / در انتظار |
| Provider; exact model ID; endpoint; timestamp / ارائه‌دهنده، مدل، سرویس، زمان | Pending / در انتظار |
| Tool/reasoning/sampling/output settings; unknown defaults / تنظیمات و پیش‌فرض نامعلوم | Pending / در انتظار |
| Raw output location/hash; all turns / محل و هش خروجی خام و همه نوبت‌ها | Pending / در انتظار |
| Status: completed/failed/blocked; reason / وضعیت و علت | Pending / در انتظار |
| Reviewer pseudonym; expertise; independent/blind status / داور، تخصص، استقلال | Pending / در انتظار |
| Relevance; feasibility; specificity / ارتباط، امکان، مشخص‌بودن | null; null; null |
| Evidence grounding; contribution; clarity / شواهد، سهم علمی، وضوح | null; null; null |
