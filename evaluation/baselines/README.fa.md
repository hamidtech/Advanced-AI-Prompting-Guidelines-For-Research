# ساخت خط مبنای تاریخی

[English](README.md)

از [آرشیو انگلیسی](../../legacy/2024-gpt-4o/EnglishGuideline.md) و [آرشیو فارسی](../../legacy/2024-gpt-4o/PersianGuideline.md) استفاده کنید. نسخه پایه `59e3911` و هش فایل آرشیو را در برنامه مطالعه ثبت کنید. فایل‌های راهنمای جدید ریشه مخزن، خط مبنای قدیمی نیستند.

فقط بلوک کد زیر عنوان «قالب تمپلیت (با جای‌خالی‌ها)» یا `Prompt Template (with placeholders)` را از بخش انتخاب‌شده بردارید؛ نمونه پرشده و توضیحات را وارد نکنید. عبارت‌های قدیمی، از جمله ادعای تنظیم خلاقیت، حفظ شوند؛ اصلاحشان خط مبنا را تغییر می‌دهد.

جای‌خالی‌ها فقط با اطلاعات همان سناریو پر شوند. اطلاعات نامعلوم «مشخص نشده» باشد و متن سناریو عیناً در پایان بیاید. پیش از اجرا، پرامپت نهایی و نگاشت جای‌خالی‌ها را ذخیره کنید. واقعیت پژوهشی اضافه نکنید. اگر سطح خلاقیت مشخص نیست، مقدار ثابت «متوسط» یا `balanced` را ثبت کنید. حالت اکتشاف جدید را جدا ثبت کنید و آن را تنظیم نمونه‌گیری API ندانید.

آرشیو برای کشف علاقه، اصلاح عنوان و امکان‌سنجی، الگوی مستقیمی ندارد. استفاده از طوفان فکری برای این کارها خط مبنای عملی با تفاوت تناسب وظیفه است؛ نتیجه آن درباره همه روش‌های تاریخی یا اثر مستقل قواعد شواهد حکم نمی‌دهد.

نگاشت کامل ده الگوی جدید در [جدول نسخه انگلیسی](README.md) آمده است: RP-01 به RTF، RP-02 به CTF، RP-03 به RASCEF، RP-04 به TAG و RP-05 به RISE نزدیک‌اند. RP-06، RP-08 و RP-10 از RTF به‌صورت غیرمستقیم استفاده می‌کنند. RP-07 خط مبنای مستقیم ندارد. برای RP-09، بخش فارسی یا انگلیسی `ThesisSummaryPrompt.md` با بسته شواهد جدید لازم است. ادعاها و اعداد نمونه‌های خلاصه‌سازی آرشیو تأیید نشده‌اند و حقیقت مبنا نیستند. سناریوهای اولیه فقط شش الگوی جدید را پوشش می‌دهند.
