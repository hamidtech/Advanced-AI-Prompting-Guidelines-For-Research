# نمونه‌های ساخت‌یافته

[English](README.md)

دو فایل JSON این پوشه نمونهٔ آموزشی ساختگی‌اند، نه یافتهٔ تجربی. متن منبع فرضی فقط این است: «روش: دوازده مصاحبه». DOI یا نشانی ناشر ساخته نشده است. «مبهم» یعنی عبارتی هست ولی معنایش روشن نیست؛ «گزارش‌نشده» یعنی اطلاعاتی در متن وجود ندارد. استنباط مدل باید از گزارش صریح منبع جدا بماند.

اعتبارسنج را از ریشهٔ مخزن اجرا کنید. کاربران مبتدی همین اطلاعات را در جدول می‌نویسند و به JSON نیازی ندارند. شِما شکل و منشأ لازم را بررسی می‌کند؛ پشتیبانی واقعی ادعا را انسان باید در متن و محل منبع بررسی کند. وضعیت بررسی‌شده به نام بازبین و شرح بررسی واقعی نیاز دارد. برای سند فاقد شناسه، شناسه نسازید.
