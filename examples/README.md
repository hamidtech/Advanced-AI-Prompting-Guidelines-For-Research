`evidence-record.json` and `topic-candidate.json` are synthetic teaching fixtures, not empirical findings. The fictional source excerpt is: “Methods: Twelve interviews.” No DOI or publisher URL is invented. An ambiguous field differs from a missing field: the former has an unclear statement, the latter lacks a statement. AI inference must remain visibly separate from source reporting.

Run the local validator from the repository root. Beginner users can produce the same fields in a table and skip JSON. Local schemas validate data shape and required provenance, not whether a source actually supports a claim. Humans must compare locators and text. A `checked` status requires an actual reviewer and an explained check (enforced by the validator). Source identifier may be absent for archival or supplied documents; do not fabricate one.
